I build [Oneiron](https://github.com/oneiron-dev/oneiron), an open-source memory engine for AI agents, written in Rust. Agents save memories to a local vault and recall them over HTTP or MCP. It is pre-release and builds from source; the [quickstart](https://github.com/oneiron-dev/oneiron#agent-quickstart-install-connect-remember) starts from a clone.

AIエージェント向けのオープンソースのメモリエンジン「Oneiron」をRustで開発しています。東京在住です。

## Selected work

- [Oneiron](https://github.com/oneiron-dev/oneiron). Memory engine for AI agents, in Rust. Agents save memories to a local vault and recall them over HTTP or MCP. Pre-release, since 2025.
- [Madoguchi](https://github.com/olety/madoguchi-aiand-hack). Entry for an enterprise-challenge hackathon. One window onto each member company's contracts and billing: a dashboard, statuses read from email with a link to the source sentence, drafted replies, and a Japanese voice agent that answers member calls. The repository holds the plan, prompts and sample data. 2026.
- [Swarm memory](https://github.com/oneiron-dev/swarm-memory). The logs of 46 AI agents over 535 days in the AI Village, read with Oneiron and turned into a [book you scroll](https://swarm-hack-2026.oneiron.dev). Every line cites its source. AI Swarm Dynamics Hackathon, 2026.
- [Errata](https://github.com/olety/errata). A browser card game made from your own Claude Code and Codex sessions. Each room is a moment where the agent went wrong, and the card you play becomes one line in CLAUDE.md or AGENTS.md. Nothing leaves the browser tab. Hackyard Yard #4, 2026.
- [amivisible.dev](https://amivisible.dev). Checks which AI crawlers can read a website, and which ones robots.txt or the CDN blocks. JSON API and MCP server, no accounts. Built solo for Hackyard Yard #1, 2026. [Source](https://github.com/olety/amivisible).
- [chinarxiv-mcp-server](https://github.com/olety/chinarxiv-mcp-server). An MCP server that lets an AI assistant search, download and read machine-translated Chinese preprints from ChinaRxiv. 2026.
- [Muse Glimmer Afterglow](https://github.com/oneiron-dev/muse-glimmer-afterglow). A local agent that runs Muse Glimmer 30B on one consumer GPU. Each night it trains a small QLoRA adapter on that GPU and keeps it only if it learned without forgetting. Built on our [Afterglow](https://github.com/oneiron-dev/afterglow) serving tools. Meta AI Developer Hackathon, 2026.
